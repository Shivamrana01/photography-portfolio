
# 📸 Shivam Studio — Photography Portfolio

A modern, responsive photography portfolio website built using HTML, CSS, and JavaScript. It showcases photography work, services, and contact information with an elegant dark theme and gold accents.

## ✨ Features

- Modern dark-themed design
- Responsive layout for mobile and desktop
- Navigation bar with active-section highlighting
- Hero section with background photography
- About section with photography introduction
- Image gallery with hover effects
- Photography services section
- Contact form that prepares an email
- Mobile navigation menu
- Smooth scrolling and interactive elements

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Google Fonts
- Unsplash images

photography-portfolio/

## 🚀 How to Run Locally

1. Clone or download this repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` in your browser.
4. For live updates during development, use the Live Server extension.

## 📷 Website Sections

- **Home:** Photography introduction and call to action.
- **About:** Photographer introduction and creative approach.
- **Gallery:** Portrait, nature, travel, wedding, and event photography.
- **Services:** Photography service categories.
- **Contact:** Form to prepare a photography enquiry email.
